V5 공개 데이터 수집 결과
기준일: 2026-11-06

V5_공개데이터_수집결과.xlsx의 '먼저읽기'부터 확인하세요.

실제로 저장한 내용
- 공개 자료원 20개: ChemExpo 자체와 대체/연계 포털, 참고 처방, 보조 자료원을 구분했습니다.
- 제품·처방 문서 10개: 상업제품 8개 + WHO 표준 처방 2개.
- 문서에서 직접 읽은 성분 조성 63행. 함량 숫자가 있는 29행 중 1행은 충돌 제품 P008에 속합니다.
- ChemExpo Explore Products 화면의 PUC 표시 항목 454행.
- 공식 파일 다운로드 주소 31개와 데이터 사전의 PPIS 필드 위치 18개.
- 웹 조사·열람 증거 텍스트, CSV/JSON/XLSX, California 카탈로그 메타데이터.

미확보·미완료
원본 전체 DB ZIP/CSV/PDF 파일 바이트를 저장한 건수는 0입니다.
이 환경의 일반 파일 다운로드 네트워크는 차단되어 있으며, 웹 도구는 CSV/ZIP 등 일부 형식을
읽지 못하거나 사이트가 403/challenge를 반환했습니다. PDF/HTML에서 읽은 내용은 텍스트로
보존했습니다. 원본 PDF/ZIP 파일을 내려받았다고 표시하지 않았습니다.
전체 공개 웹을 망라한 목록이 아니며, 개별 DB 전체 수집도 완료되지 않았습니다.

이전 V4 수집 기준과의 관계
이번 V5는 제품 조성의 공개 원천을 찾고 실제 읽을 수 있는 조성 자료를 모은 것입니다.
실제 동물 피부/눈 자극시험과 EPA 등급이 함께 확인된 신규 학습 표본은 0개입니다.
현재 제품·처방 10개를 V4 실험 표본 수에 합산하지 마세요.
기존 V1–V4와의 제형 중복 확인은 수행하지 않았습니다.
경고문, GHS 분류, 등록번호, NDC, WHO 권고만으로 피부/눈 EPA 값을 생성하지 않았습니다.

우선 활용할 원천
1. ChemExpo bulk composition: 제품·문서·조성 연결. reported vs predicted 농도를 구별해야 합니다.
2. EPA PPIS: formula.zip + product.zip + chemcas.zip + chemname.zip + formname.zip.
   FORMULA의 PC_PCT는 활성성분 함량입니다. 비활성 성분 전체 처방은 아닙니다.
   PRODUCT의 TOX_CODE는 Danger=1, Warning=2, Caution=3, None=0의 signal word 코드입니다.
   피부·눈 EPA endpoint로 사용할 수 없고 None=0을 EPA IV로 바꾸면 안 됩니다.
3. ECHA SPC: 활성/일부 비활성 성분의 함량. 활성 모이어티, 원료/releaser, meta-SPC 범위를 구별하세요.
4. CPID/제조사 SDS: 공개 성분명·CAS·범위. 개정일과 제품코드를 함께 보존하세요.
5. DailyMed: 활성성분 함량과 비활성 목록/일부 함량. UNII는 CAS가 아닙니다.
6. CSCP/HPCDS/초록누리/PTDB: 신고 성분 또는 측정 농도. 전체 처방·동물 독성과 구분하세요.

주요 데이터 해석
- 제품목록: 제품/문서 단위. 포장별 NDC를 별도 처방으로 세지 않았습니다.
- 성분조성: 원문 단위, 범위, CAS/UNII, 출처 URL·위치를 보존합니다.
- value_min/value_max는 unit_raw의 숫자입니다. 일괄 weight %가 아닙니다.
- 미공개 값은 빈칸입니다. 0으로 채우거나 물의 잔량을 100에서 차감하지 않았습니다.
- P008 과산화수소는 본문 3%와 SPL 3 mL/1 mL가 충돌합니다. 제품 전체를 보류했습니다.
- P002의 Percent는 질량/부피 기준이 명시되지 않았습니다.
- WHO 표준 처방은 최종 % v/v만 기록했고 원료 용액의 투입 농도와 구분했습니다.
- PUC 파일은 화면에서 읽힌 분류 라벨/표시 수치입니다. 공식 PUC ID·부모 계층은 미확보입니다.
  동일 라벨이 여러 위치에 있을 수 있으며 표시 개수를 합산해 고유 제품 수로 해석하지 마세요.
- SDS는 2005/2013/2015년 등 과거 문서도 포함합니다. 현재 판매 제품의 최신 처방으로 단정하지 마세요.
- 공개 열람 가능성과 자유 재배포 라이선스는 다릅니다. 원문별 이용조건을 확인하세요.
  CSCP 카탈로그는 CC BY로 표기되어 있습니다. 기타 라이선스는 일괄 추정하지 않았습니다.

원본 다운로드 재시도
이 폴더에서 다음 명령으로 목록만 확인할 수 있습니다.
  python -X utf8 download_public_data.py --list
네트워크가 허용되는 환경에서 기본 선택 24개 파일 다운로드:
  python -X utf8 download_public_data.py --download
특정 파일만 선택:
  python -X utf8 download_public_data.py --download --id D015 --id D016 --id D017 --id D018
대용량 DailyMed OTC part 1은 기본에서 제외했습니다(전체 6부분 중 하나).
  python -X utf8 download_public_data.py --download --id D023 --max-mb 4096

다운로드 스크립트는 이 폴더의 원본파일 폴더에만 쓰며 기존 파일을 덮어쓰지 않습니다.
HTML 오류 응답을 ZIP/PDF로 저장하지 않고 파일 크기 제한과 ZIP/PDF 서명을 검사합니다.
압축파일을 자동으로 풀지 않습니다. 별도 다운로드_실행기록.jsonl에 실제 성공/실패와
SHA-256을 기록합니다. 이번 수집결과.json/엑셀의 조사시점 상태는 자동 변경하지 않습니다.
스크립트 문법/목록 출력/파일 검증은 로컬에서 확인했지만 네트워크 다운로드 성공은 검증하지 못했습니다.

재현
  python -X utf8 _scripts/export_v5.py

연결 확인 및 행 수 검증 결과는 수집검증.json에 있습니다.
