ChemBERTa 기반 안자극 전이학습 실험 결과
작성일: 2026-11-09

1. 결론
안자극(Eye EPA) head를 실제 학습하고 평가했다. Zein은 학습·평가에 사용하지 않았다.
그러나 이번 고정 설정의 내부 홀드아웃에서는 ChemBERTa 기반 모델이 동일 학습 분할의 LR 비교 모델보다 낮은 점수를 보였다. 기존 Eye LR를 교체할 근거는 확보하지 못했다.
독립 EPA 외부시험 데이터가 없어 외부검증은 미완료다. 아래 결과는 내부 그룹 홀드아웃 평가이며 화장품 완제품 안전성 검증이 아니다.

2. 무엇을 학습했는가
보관된 ChemBERTa MLM 인코더는 고정하고, 384차원 성분 임베딩의 함량 가중평균을 입력으로 새 로지스틱 Eye head를 학습했다. 이는 사전학습 표현을 전용하는 전이학습이며 인코더 미세조정은 아니다.
정답: EPA I/II=1, III/IV=0. 0은 무자극·안전 보증을 뜻하지 않는다. 점수는 보정된 실제 발생 확률이 아니다.
출처 인코더: mixture-003 보관본, MLM 학습 mixture-002, DeepChem/ChemBERTa-77M-MLM 계보. 인코더 SHA-256은 encoding_summary.json에 기록했다.
현재 최종 Eye LR 모델 파일과 인코더 원본은 수정하지 않았다.

3. 데이터와 분할
기존 Eye EPA 스냅샷 673행을 사용했다. 283개 고유 SMILES 중 3개는 128토큰 제한을 넘었다. 구조를 자르거나 누락 성분을 제거하지 않고 해당 성분을 포함한 제형 20행 전체를 제외했다.
학습 533행: 음성 432, 양성 101 / 322그룹.
홀드아웃 118행: 음성 95, 양성 23 / 63그룹.
기존 augmentation_train_only 67행은 평가에 넣지 않았으며, 평가 그룹과 연결된 2행을 학습에서도 제거했다.
기존 split/배합/구조 그룹 및 동일 특징 벡터의 연결 성분을 통합한 뒤, seed 42의 5분할 중 첫 분할을 고정했다. 결과를 보고 유리한 분할을 선택하지 않았다.
같은 그룹과 같은 전체 입력 벡터가 학습·평가에 동시에 들어가지 않음을 검증했다. 다만 평가의 고유 성분 98종 중 65종은 학습에도 등장한다. 미지 성분 일반화 평가가 아니다.
원자료의 상충 그룹 플래그를 예측에 맞춰 수정하거나 선택적으로 삭제하지 않았다. 역할별 집계는 label_conflict_audit.json에 보존했고 관련 입력은 같은 그룹으로 묶었다.

4. 공정 비교 조건
새 Eye head: C=1.0, max_iter=5000, 학습 자료 내 클래스별 균형 가중치, 임계값 0.5.
LR 비교 모델: 기존 LR 파이프라인을 복제하고 C=0.0001을 유지한 채 정확히 같은 학습 행으로 새로 fit. 학습 클래스 가중치와 임계값 0.5를 동일 적용.
결측 대체·스케일러는 각 모델의 학습 행에만 fit했다. 최종 LR의 전체 673행 학습 완료 체크포인트를 홀드아웃 비교 대상으로 쓰지 않았다.
기존 운영 임계값 0.481487을 이번 결과에 맞춰 조정하지 않았다. 이번 실험의 두 모델은 사전 고정한 0.5를 사용한다.
서로 다른 표현과 사전 고정 C를 비교한 단일 실험이다. 결과 차이를 인코더 자체의 우열로 단정하거나 ChemBERTa의 모든 설정이 열등하다고 일반화하지 않는다.

6. 검증과 제한
26개 자동 점검 통과: 입력·모델·프로토콜 해시, 그룹/동일 벡터 누출, 학습 전용 스케일링, 저장 모델 재추론, 지표 재계산, 원시 SMILES→인코더→Eye head 실행, 잘못된 입력 거부.
추론 확인에 사용한 다성분 홀드아웃 행: 23. 저장 특징 점수 0.04189185, 원시 구조 재인코딩 점수 0.04189195.
학습 결과가 낮게 나와도 평가 자료에 맞춰 C·임계값·분할을 다시 고르지 않았다. float32 중간값의 저장 후 수치 차이를 줄이기 위해 head 학습/추론은 float64로 통일하고 재검산했다. 인코더 임베딩은 원래 float32를 유지한다.
원자료와 기존 LR 설정은 이전 연구에서 이미 검토된 자료다. 이번 분할은 완전히 새로운 전향적 자료가 아니다. 인코더의 상위 사전학습 코퍼스 중복 여부도 미확인이다.
STopTox는 GHS 기반 눈자극 자료라 EPA 정답으로 자동 변환하지 않았다. 현재 확인한 화장품 자료에는 독립적인 EPA 정답·배합·원시험 연결이 확보된 외부 세트가 없다.
따라서 '안자극 모델 학습 및 내부 평가 완료, 독립 외부 평가 미완료'가 정확한 완료 범위다.
