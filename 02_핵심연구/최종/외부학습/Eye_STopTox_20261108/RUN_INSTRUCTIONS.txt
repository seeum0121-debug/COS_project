To reproduce in a NEW sibling directory under eye/claude:
1. Copy only the .py scripts and the sources directory into that new directory.
   Do not copy checkpoints, .running locks, or generated result tables.
2. Run from that new directory, in this order:
   python -B prepare.py
   python -B review_cosmetics.py
   python -B analyze_cases.py
   python -B verify_transfer.py --preparation-only
   python -B run_transfer.py --workers 10
   python -B verify_transfer.py
   python -B build_report.py
3. Compare file identities and numerical results. The protected input/source code
   hashes and installed package versions must match the saved production config.

UVCB/polymer exclusions. Reproduction itself makes no network requests.

was interrupted externally, verify that its recorded PID and workers have ended
before recovering the stale lock. Never remove a lock for an active experiment.
prepare.py and final report writers deliberately refuse to overwrite artifacts;
use a fresh sibling directory for a clean rerun.
