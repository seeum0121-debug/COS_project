Eye 외부학습 최종 자료

Eye_STopTox_20261108 폴더에서 다음 파일을 먼저 열면 됩니다.
  RESULTS.txt — 실험 결과, 한계, 외부검증 판정
  eye_external_auxiliary_validation.ipynb — 실행 결과가 포함된 노트북

포함 자료
- 실제 학습에 사용한 STopTox 3,261행과 전체 행별 제외 사유
- 학습된 보조모델(stoptx_teacher.joblib)과 보조 특성
- 같은 606행에서 비교한 성능표, seed별 ΔMCC, 행별 OOF 예측과 그림
- 화장품 관측 검토표와 공급업체·농도 사례 분석
- 실행 당시 코드, 환경, 프로토콜, 설정과 검증 기록
- 검증체크포인트.zip: 신규 90 outer 결과와 1,800 후보 기록
- sources: 핵심 논문·보충자료, UVCB 검사 목록, 원본 Table S4 CSV와 출처 기록

파일 안내
  paired_summary.csv / paired_delta_by_seed.csv — 핵심 비교 결과
  stoptx_aux_training.csv — 실제 외부학습 자료
  stoptx_identity_audit.csv — 외부 원본 3,545행의 채택·제외 사유
  external_validation_audit.json — 화장품 외부검증 가능성 판정
  verification.json — 실험 결과 검증 기록
  relocation_manifest.json — 이번 파일 이동 내역
  package_checksums.json — 현재 보관 자료의 SHA256

이동과 원본 보존
최종 실험에서 필요한 파일을 이 폴더로 이동했습니다.
공용 조사 폴더의 원본 Table S4 CSV와 다운로드 출처 기록은 원래 위치를 유지하고 사본만 포함했습니다.
예비/중단 실행, 실패 응답 HTML, 반복 콘솔 로그, 표 추출 이미지·텍스트와 중복 CSV는 옮기지 않았습니다.
상세 후보 JSON은 압축본으로 포함했습니다. 압축 전 파일은 이전 실험 위치에 그대로 보존했습니다.
기존 production 입력·코드·결과와 기존 종합 노트북은 이동하거나 수정하지 않았습니다.

노트북과 재현
노트북은 Eye_STopTox_20261108을 작업 디렉터리로 읽을 수 있습니다. 기존 실행 출력도 들어 있습니다.
코드는 실행 당시 원본 그대로 보존했습니다. common.py는 원래 eye/claude 아래의 배치를 가정합니다.
재학습하려면 RUN_INSTRUCTIONS.txt에 따라 .py 파일과 sources를 기존 eye/claude 아래 새 폴더로 복사하세요.
체크포인트를 감사/재개할 때는 검증체크포인트.zip을 풀어 runs 하위 경로를 복원합니다.
기존 production 입력과 공용 조사·성분 자료는 기록된 기존 로컬 경로를 계속 사용합니다.
이 보관 폴더가 다른 컴퓨터에서 단독 실행되는 배포 패키지라는 뜻은 아닙니다.

기록의 경로
RESULTS.txt와 일부 JSON의 이전 절대경로는 실행 당시의 경로입니다.
파일 이동 때문에 실험 코드나 검증 결과를 다시 작성하지 않았습니다.
original_run_checksums.json은 당시 전체 실험의 해시 기록이며, 옮기지 않은 중간 파일도 포함합니다.
현재 보관 파일의 검증에는 package_checksums.json을 사용하세요.

해석
외부자료 보조학습은 수행했습니다. 일관된 개선은 확인되지 않았고 독립 화장품 외부 성능은 미검증입니다.
