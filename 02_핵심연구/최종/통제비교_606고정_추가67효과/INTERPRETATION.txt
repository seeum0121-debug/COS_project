606행 고정 분할 통제 비교실험 — 해석

1. 실험과 검증
- 평가 대상은 기존 606행, 외부·내부 그룹 분할은 과거 실험과 동일하게 고정했다.
- 추가 67행을 학습에 활용한 기존 조건과, 모든 학습 단계에서 제외한 새 조건을 비교했다.
- LR/RF/XGBoost × 가중평균/최댓값 6조합, 3시드 × 외부5/내부3, 모델별 기존 20개 후보를 유지했다.
- 전처리·가중치·설정·임계값은 각 학습/내부 검증에서만 결정했다.
- numpy, pandas, scikit-learn, xgboost의 과거·현재 버전이 모두 같음을 확인했다.
- 기존 조건은 체크섬과 후보 선택·임계값을 검증한 과거 결과를 재사용했다. 과거 모델 바이너리가 없어 해당 모델 자체를 재구성하지는 않았다.
- 신규 90개 외부 모델은 저장된 모델로 평가 예측을 재계산했다. 총 21,816개 paired OOF 기록과 지표·차이표 검증을 통과했다.

2. LR·가중평균: 추가 67행이 소폭 불리했다
내부 검증으로 고른 임계값 기준, 3시드 평균:
조건                 민감도      특이도       MCC        AUC
추가 67행 제외       0.704348    0.688391    0.316422   0.725063
추가 67행 활용       0.704348    0.677529    0.306327   0.718929
차이(활용-제외)      0.000000   -0.010862   -0.010095  -0.006134

AUC는 3시드 모두 추가 자료 활용 조건에서 낮았다. MCC는 3시드 중 2시드에서 낮았다.
0.5 고정 임계값에서도 MCC가 0.337270(제외)에서 0.321878(활용)로 낮아졌다.
따라서 이 조건에서 관찰된 차이는 임계값 재선정만으로 설명되지는 않는다.
단, 추가 데이터 정책이 클래스 가중치·모델 적합·설정 선택에 미치는 반응을 모두 포함한 효과이며, 67행의 라벨이 틀렸다는 증거는 아니다.

4. 원래 질문인 '606행 평가에서 673행 평가로 바꿨을 때의 하락'과는 구분해야 한다
중요: 과거 606행 평가 때도 추가 67행을 학습에 활용했다. 새 실험에만 67행이 들어간 것이 아니다.
따라서 위 추가자료 제외 실험만으로 과거→현재 성능 하락을 모두 설명할 수 없다.

LR·가중평균의 관찰 결과를 나누면:
A. 과거 방식, 기존606 평가: AUC 0.718929 / MCC 0.306327
B. 새 방식, 기존606만 집계: AUC 0.712294 / MCC 0.292602
C. 새 방식, 전체673 집계: AUC 0.716097 / MCC 0.294342

A→B: AUC -0.006635 / MCC -0.013725
평가 행의 신원은 같지만 그룹 분할, 각 폴드 학습량, 내부 설정·임계값 선정 자료가 바뀐 복합 차이다.
이 비교만으로 분할 영향과 학습량 영향을 각각 분리할 수는 없다.

B→C: AUC +0.003804 / MCC +0.001741
같은 새 모델들의 예측을 유지한 채 집계 대상만 606에서 673으로 넓힌 변화다.
추가67을 평가 대상에 포함한 것 자체는 이 두 지표를 오히려 높였다.
비선형 지표이므로 이 차이는 표본별 기여를 단순 가중평균한 값이라는 의미가 아니다.

고정0.5로 비교해도 기존606에 대한 민감도는 과거 0.623188에서 새 방식 0.573913으로 낮아졌다.
즉 평균 임계값 상승만이 과거→현재 차이의 원인이라는 해석도 충분하지 않다.

5. 결론과 권고
- 추가 67행은 LR·가중평균의 과거606 고정분할 성능에는 소폭 불리했으나, 다른 조합에서는 도움이 되기도 했다.
- 실제 606→673 보고 지표 하락은 '평가에 67행을 추가했기 때문'이라고 볼 수 없다. 기존606에 대한 새 학습/분할 절차의 차이가 더 큰 관찰 변화였다.
- 673행 전체 평가를 유지하고, 추가 자료의 출처·라벨 일관성·성분 표현과 목표 사용집단 적합성을 검토하는 것이 적절하다.
- 작은 내부 성능 차이만 보고 67행을 자동 삭제하거나 최종 모델을 교체하지 않았다. 기존 최종 모델 두 폴더는 변경하지 않았다.
- 3시드는 독립 코호트가 아니며 표준편차는 기술통계다. 통계적 유의성이나 외부 일반화 개선을 확정하지 않는다.

6. 파일과 재현
RESULTS.txt / metrics_summary.csv: 두 조건의 전체 결과
paired_deltas.csv / paired_delta_summary.csv: 동일 시드·모델의 차이
existing_protocol_metrics.csv / existing_protocol_deltas.csv: 과거/새 방식과 평가 집단의 관찰적 분해
selected_settings.csv / threshold_summary.csv: 설정·임계값 변화
controlled_config.json: 고정 분할, 환경, 코드·입력·기준선 해시
audit.json: 결과 검증 기록

재개 및 검증 명령:
python run_controlled.py --workers 6
python verify_controlled_results.py
python analyze_existing.py

검증기 수정 기록:
초기 audit_controlled.py는 sklearn의 상수 대체기 statistics_가 object dtype인 경우 수치 비교에서 TypeError를 냈다.
실제 저장값은 모두 숫자 0임을 확인한 후, float 변환만 추가한 verify_controlled_results.py로 전체 감사를 통과했다.
훈련 코드와 모델·평가 결과·비교 허용오차는 변경하지 않았다. 원래 해시가 고정된 감사 스크립트는 기록 보존을 위해 유지했다.
auditor_correction.json에 수정 전후 해시와 사유가 기록되어 있다.
